## Project Description

CommunityHub is a sports community web application that allows users to register, view posts, and interact with other members through comments.

The application provides a simple and responsive platform for sports fans to view community content and participate in discussions.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- React
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- Git
- GitHub

## Features

- User registration
- User login
- Display posts
- Add and view comments
- Responsive design
- MongoDB database integration
- REST API
